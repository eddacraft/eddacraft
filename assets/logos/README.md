# Public brandmarks

Hotlinkable copies of the official marks from private
`eddacraft/brand-and-design` (`logos/svg/`). Copy out; do not fork.

Brand hierarchy (`BRAND_README.md` §2):

- **eddacraft** — parent company. Org chrome, GitHub org page, Access login avatar.
- **anvil** — flagship product. Product surfaces, the anvil Access *application*.

Pick the mark for the background it sits on:

- Dark / void → `*-white` (off-white fill, transparent).
- Light / white → `*-void` (void fill, transparent).
- Mixed → `eddacraft-white-on-void.svg` (off-white mark on a void tile).

Cloudflare Access draws the org avatar on a white card, so that slot uses
`eddacraft-brandmark-void.svg`.

| File | Entity | Use |
| --- | --- | --- |
| `eddacraft-brandmark-void.svg` | company | Light backgrounds. Cloudflare Access org avatar. |
| `eddacraft-brandmark-white.svg` | company | Dark backgrounds. |
| `eddacraft-white-on-void.svg` | company | Mixed backgrounds. GitHub org page. |
| `anvil-brandmark-white.svg` | product | Dark backgrounds. anvil app / product UI. |
